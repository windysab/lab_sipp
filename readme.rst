#####################
Lab SIPP - Sistem Informasi Penanganan Perkara
#####################

Lab SIPP adalah aplikasi berbasis web untuk pengelolaan data perkara di lingkungan peradilan agama. Aplikasi ini membantu proses administrasi, pelaporan, dan monitoring perkara seperti Dispensasi Kawin, Penyerahan Akta Cerai, dan fitur-fitur lain yang relevan dengan kebutuhan pengadilan.

*******************
Fitur Utama
*******************

- Laporan Dispensasi Kawin (Diska)
- Laporan Penyerahan Akta Cerai (AC)
- Filter data berdasarkan bulan/tahun
- Statistik dan rekap data perkara
- Ekspor data ke Excel/PDF
- Tampilan modern dan responsif

*******************
Persyaratan Server
*******************

- PHP 7.2 atau lebih baru
- MySQL/MariaDB
- Web server (Apache/Nginx)
- Ekstensi PHP: mysqli, mbstring, json, dan lain-lain

************
Instalasi
************

1. Clone repository ini ke server lokal Anda.
2. Import database dari file SQL yang tersedia.
3. Atur konfigurasi database pada `application/config/database.php`.
4. Pastikan base_url pada `application/config/config.php` sudah sesuai.
5. Jalankan aplikasi melalui browser.
